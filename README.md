# 家庭记账 App（Family Home）

面向家庭场景的记账应用：以「家庭 + 账本 + 记账」为核心，支持多用户协作、多账本（公共 / 个人）、多账户组合付款、预算与统计。后端为纯 API 服务，未来可扩展微信小程序、iOS App 等多端客户端。

## 功能特性

- **多端规划**：v1 交付网页端（Vue 3 SPA）；后端接口按多端复用设计，微信小程序 / iOS App 规划在 v2。
- **多用户与家庭**：手机号验证码登录；创建家庭 / 邀请码加入；家庭入口在右上角用户下拉菜单。
- **多账本**：支持公共账本（家庭成员共享全部账单）与个人账本；创建者可管理成员、分类、标签、主题外观。
- **记账**：支出 / 收入 / 转账三类；必选账户，支持**多账户组合付款**；可记录备注、标签、记账人（公共账本可代记）；支持连续记账。
- **账户资产**：三类账户——**资金账户**（现金 / 银行卡 / 微信 / 支付宝 / 京东钱包 / 抖音钱包等）、**信贷账户**（信用卡 / 花呗 / 白条 / 房贷 / 车贷 / 装修贷等）、**储值账户**（会员卡 / 公交卡 / 加油卡等）；支持推荐账户快捷新建与自定义；余额调整留痕；资产总览（总资产 / 总负债 / 净资产）。
- **预算**：按分类设置预算，周期支持按月 / 自定义；超支提醒与标记。
- **统计**：收入支出趋势、分类占比。
- **操作留痕**：账单的修改、删除均有审计日志，账单详情以时间线卡片展示（操作人 + 变更摘要 + 时间）。
- **设置**：账户信息查看、成员查看、账本新建 / 删除。

## 技术栈

| 模块 | 技术栈 |
| --- | --- |
| 前端 | Vue 3 + TypeScript + Vite 5 + Element Plus + Pinia + ECharts |
| 后端 | Spring Boot 3.2 + Java 17 + MyBatis-Plus + JWT |
| 数据库 | 开发 / 测试：H2（内存，MODE=MySQL）；生产：MySQL 8 |

## 快速开始

### 1. 初始化数据库（生产 / 需要 MySQL 时）

```bash
mysql -u root -p < sql/schema.sql
```

脚本会创建数据库 `family_home`（utf8mb4）及全部 12 张表。开发环境默认使用内存 H2，启动时自动建表，无需安装 MySQL。

### 2. 启动后端

```bash
cd backend
set JAVA_HOME=C:\你的JDK17路径
mvn spring-boot:run
```

- 默认端口 `8080`，开发环境验证码固定为 `123456`（`app.sms.debug=true`）。
- 接口文档：`http://localhost:8080/swagger-ui.html`。

### 3. 启动前端

```bash
cd frontend
npm install
npm run dev
```

- 开发服务器将 `/api` 代理到 `http://localhost:8080`。
- 浏览器访问 `http://localhost:5173`。

### 4. 首次使用流程

1. 注册 / 登录（手机号 + 验证码，开发环境任意手机号验证码为 `123456`）。
2. 创建或加入家庭（家庭有 8 位邀请码，成员凭码加入）。
3. 创建账本（个人 / 公共；公共账本需先有家庭，家庭成员自动入账本）。
4. 新增账户（资金 / 信贷 / 储值三类）。
5. 记一笔：支出 / 收入 / 转账，多账户组合付款，可加备注、标签、记账人。

## 版本规划

- **v1（当前）**：网页端全量功能——手机号验证码登录、家庭 / 成员、个人 + 公共账本、分类 / 标签管理、记账（三类 + 多账户付款 + 留痕）、账户资产（三类账户 + 资产总览）、预算、统计、设置。
- **v2（规划）**：微信登录（接口已预留，需备案域名 + 企业主体）、微信小程序、iOS App、借入借出、更多统计维度。
